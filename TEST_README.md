# Test Notes

The previous embedded-provider test utilities have been deprecated. SuperEmbed (multiembed.mov) is now the default streaming provider. Use iframe URLs such as:

- Movie: https://multiembed.mov/?video_id=tt6791350
- Episode: https://multiembed.mov/?video_id=114472&tmdb=1&s=1&e=2

All legacy scripts under this directory now emit deprecation messages.
